# Ask

Ask a question and get an answer from your own documents, with the sources it used.

A brain app for [BRAINF](https://github.com/gregorygerman777-hub/BRAINF). It runs as a tab
(`/ask`) inside your brain and talks to it through the console's app bridge.

- Permissions: `llm.invoke`
- Memory layers: episodic (read), semantic (read), procedural (read)

## Install

In your brain: **Settings > Apps**, paste
`https://github.com/gregorygerman777-hub/brain-app-ask` and approve.

## Files

- `brain-app.yaml`: the manifest (`brain-app/v1`)
- `dist/index.html`: the whole app, no build step
